## 1. Overview

The Hack The Box Certified Penetration Testing Specialist (CPTS) is a hands-on cybersecurity certification designed to assess practical penetration-testing competency. Unlike training that primarily evaluates knowledge through quizzes or multiple-choice examinations, the CPTS pathway emphasizes technical exercises, applied problem-solving, realistic assessment scenarios, and the production of a professional penetration-testing report.

My objective is to progress beyond understanding cybersecurity concepts and individual tools toward demonstrating that I can apply that knowledge systematically: enumerate an environment, identify security weaknesses, investigate exploitation opportunities, connect vulnerabilities into meaningful attack paths, evaluate impact, and communicate findings through a professional report.

Hack The Box describes the CPTS as an intermediate-level certification that evaluates practical penetration-testing skills across web applications, external and internal infrastructure, Windows and Linux systems, and Active Directory environments. The certification also emphasizes vulnerability chaining, risk assessment, and actionable reporting.

## 3. The Distinction Between Knowing and Doing

One of the most important reasons for pursuing this certification is the difference between understanding a security concept and being able to apply it effectively.

A person may understand what SQL injection is, recognize the purpose of a network scanner, or explain the principle of least privilege without necessarily being able to conduct a complete assessment independently.

Practical penetration testing demands additional capabilities:

- Knowing which tool or technique is appropriate for the situation.
- Interpreting results rather than simply running commands.
- Recognizing when an initial hypothesis is incorrect.
- Investigating unexpected behavior.
- Identifying relationships between separate weaknesses.
- Adjusting the approach as new evidence becomes available.
- Distinguishing a theoretical vulnerability from a demonstrated finding.
- Explaining the impact and recommending an effective remediation.

The CPTS pathway is designed to help develop and assess these applied capabilities through structured learning, hands-on exercises, and a practical certification assessment.

**The distinction I want my portfolio to communicate is that I am working toward evidence of applied skill, not merely accumulating course-completion records.**

## 4. Core Technical Areas

The official CPTS pathway covers a broad range of penetration-testing activities. The following areas represent the technical competencies I am working to develop through this program.

### 4.1 Reconnaissance and Enumeration

Reconnaissance and enumeration establish an understanding of a target environment and its potential attack surface.

This includes learning to identify exposed services, understand how those services operate, collect relevant information, and prioritize areas for further investigation.

The goal is to build an evidence-based understanding of the target rather than immediately attempting exploitation.

### 4.2 Vulnerability Assessment and Exploitation

Penetration testing requires identifying weaknesses and determining whether they can be meaningfully validated.

I am working toward stronger competency in recognizing misconfigurations, assessing application behavior, evaluating potential exploitability, and understanding the conditions required for a successful attack.

This also means understanding the limitations of automated tools and knowing when manual investigation is necessary.

### 4.3 Web Application Security

Web applications introduce security considerations involving authentication, session handling, input validation, authorization, application logic, and interactions with underlying services.

The pathway provides structured opportunities to study web application assessment and develop a more systematic approach to finding and validating weaknesses.

This builds upon my existing ethical-hacking coursework and Cisco CTF experience.

### 4.4 Linux and Windows Security

Understanding the operating systems being assessed is essential to effective penetration testing.

Relevant competencies include system enumeration, permissions, service configuration, credential security, privilege boundaries, and the investigation of potential privilege-escalation paths.

My existing Linux and self-hosting experience provides a useful technical foundation, while the CPTS pathway offers an opportunity to apply that foundation to structured offensive security assessments.

### 4.5 Active Directory and Enterprise Infrastructure

Enterprise environments introduce additional complexity through centralized identity, authentication, permissions, domain relationships, and interconnected systems.

The CPTS pathway includes Active Directory assessment and attacks, providing a structured route toward understanding how identity and configuration weaknesses can affect a wider network.

This is particularly important for developing beyond isolated lab targets toward multi-system assessment scenarios.

### 4.6 Pivoting and Lateral Movement

In a network assessment, an initial point of access may expose additional systems or resources that are not directly reachable from the original testing position.

Understanding pivoting, tunneling, and lateral movement helps explain how network architecture and trust relationships affect the potential scope of a compromise.

These techniques must always be practiced within explicitly authorized environments and within the defined assessment scope.

### 4.7 Professional Reporting

A penetration test is not complete simply because a technical objective has been achieved.

A useful assessment must communicate what was discovered, how the finding was validated, what impact it may have, and how the organization can address it.

The CPTS places particular emphasis on producing a professional, actionable report. This is an important part of the certification's value because it connects technical execution with the communication and documentation expected in professional security work.
